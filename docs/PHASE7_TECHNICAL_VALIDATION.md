## Detailed checks

- `npm run typecheck`: 0 errors.
- `NODE_OPTIONS='--import ./scripts/loopback-only.mjs' npm run build`: success. The helper only restricts Astro's font helper server to loopback; it does not alter the build output.
- Listener check during work: only `127.0.0.1:4321` (dev) and the temporary `127.0.0.1:4322` (production check), both loopback. The 4322 server was terminated after use.

### Navigation and content gates

- `node scripts/verify-phase6.mjs dev`: themes rendered with `data-theme-review="local-only"`, six issue drafts reachable, unknown issue 404, anchor targets resolve, English-only text, no PDF/DOCX/PPTX/MP4 links, private paths excluded from `<main>`.

- `node scripts/verify-phase4-http.mjs`: 14 routes, single `<h1>`, English, draft boundary labels, no original downloads.

### Responsive layout and embedding

- Mobile emulation 375×812 (DPR 2): `scrollWidth === clientWidth` on theme and video pages; primary navigation wraps correctly; "Explore topics" disclosure works.
- Video page: before interaction, 0 iframes; after "Load YouTube player", one iframe `https://www.youtube-nocookie.com/embed/RPXnSvabsGY?rel=0&playsinline=1&hl=en`, `referrerpolicy=strict-origin-when-cross-origin`, `allowfullscreen`. The video ID is validated by regex in `YouTubePlayer.astro`.
- Observation: the embedded player shows the YouTube channel name in Japanese. This comes from YouTube channel metadata, not site content; decide whether the channel display name should be English before publication.
